# AmbientTact Website

Static research website for AmbientTact / Salesforce AI Research.

## Local preview

Run from this directory:

```sh
python3 -m http.server 8771 --bind 127.0.0.1
```

Open http://127.0.0.1:8771/.

## Contents

HTML, CSS, JavaScript, the 4K overview video and poster, ten carousel PNGs, the framework image,
the evaluation radar SVG, favicon, and linked manuscript draft PDF.
Full-size carousel links use the same original-resolution PNGs.

## GitHub Pages

When ready, publish the repository's main branch from its root directory.
The .nojekyll file allows these static assets to be served directly.
No build process or package installation is required.
